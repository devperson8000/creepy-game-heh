# B2 hooded figure reference images

Character reference previews reviewed for the Halloween B2 encounter. These images are saved for selection; they are not installed game characters.

The latest candidate is **Hooded Figure 3d Model Free by iRahulRajput**. The intended treatment is entirely black clothing and fittings, a featureless black hood interior, subtle monitor lighting, and restrained movement. Its mesh needs optimization and animation work before use.

![Latest candidate: black hooded figure](black-hooded-figure.jpg)
