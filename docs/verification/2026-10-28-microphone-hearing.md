# Microphone hearing — current game

Enabled co-op microphones now create bounded noise events at host-authoritative player positions. Soft voice, talking, shouting, screaming and sprinting plus screaming have radii 5, 12, 24, 36 and 44 respectively; sprinting alone remains 17. Walls retain their existing attenuation. Screams interrupt ordinary roaming and start a chase to the last heard position at the existing chase speed. Silence does not reveal future positions; existing sight loss, search and roaming still apply.

Closets muffle voice to 35% and emit at their real entrance. Only an actually heard voice makes that entrance known; capture still uses the existing distance and visibility checks. Muted, stale, downed and escaped microphones cannot emit fresh clues. Arrival, waiting-room and finale audio never becomes gameplay noise. Living survivors can still give themselves away while using the co-op pause menu, since the world continues moving.

The microphone panel shows local loudness and saves a bounded sensitivity control. Browser echo cancellation/noise suppression remain enabled; automatic gain is disabled to avoid turning quiet speech into loud speech. Detection uses separate sustained thresholds, rejects brief peaks/DC/tiny noise, and never records or transcribes. Gameplay input carries only a level and sequence number, separately from historical movement commands. No extra input/action stream or synthesized voice Foley was introduced.
