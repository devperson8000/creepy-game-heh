# Halloween update gap audit

Scope: approved metal/audio, historical recap, house escape, mounted key and B2 scene pass. This is an evidence-based follow-up list, not a claim that untested devices/networks have no lag. Recorded against the halloween-story branch on 23 October 2026.

| Priority | Gap | Evidence and useful next step |
| --- | --- | --- |
| Before replacing the public teaser | Selected Needlelimbs model/rig is absent. The older three-creature public edit remains; the new private edit clearly labels its missing actor. | `src/teaser-edition.js` has `NEEDLELIMBS_READY=false`; no `public/models/teaser/needlelimbs.glb`. Obtain the selected source with its licence, review the rig and natural locomotion/peek, then enable the prepared edit. Do not replace it with an unrelated monster or expose an empty-actor preview as finished footage. |
| Art decision before launch | The selected Hooded Wanderer source is absent. The B2 figure is an improved authored black-cloth stand-in. | `src/hooded-stranger.js` and the private test hub disclose this. Either deliberately adopt this authored figure or import the chosen source and retarget the now-tested switch/head gestures. The current quest and dialogue function without that source. |
| Before launch QA | Real four-person and real-phone playthroughs still need coverage. | This pass covers real host/guest transport, hidden-host victory, solo, 1–4 player geometry/state and phone browser framing. A headless two-tab test cannot establish real mobile frame rate, touch comfort, battery/thermal behaviour or four separate users' networks. Play the whole quest, down/revive, B2 return and ending on the intended devices. |
| Startup/performance follow-up | The game prepares archive/teaser resources when a Halloween round starts, and the build still has the existing large-chunk advisory. | `createHalloweenExperience()` immediately creates teaser playback; the public legacy teaser loads approximately 3.3 MB of creature GLBs. Final app/Three chunks are approximately 633/584 kB before gzip. Lazy-load B2 media nearer its first use and profile shader warm-up/draw cost on phones before choosing further optimisations. The new standalone ending preview warms shaders before advancing its clock. |
| Horror/gameplay improvement | Monster audio has distance falloff and a metal bus, but no positional panner or wall occlusion. | `src/monster-audio.js` connects its bus to the destination and updates scalar `monsterGain(distance)`. Directional left/right cues and muffling through walls would make the now-longer warning range more useful and believable. |
| Reliability enhancement | A lost host/long gameplay disconnect ends the session rather than resuming the run. | `src/coop-game.js` uses the owner as authority and shows CONNECTION LOST after closure or missing snapshots. Rejoin/recovery and host migration are separate features that need explicit design and authority tests; they are not solved by movement interpolation. |
| Optional continuity polish | The intro begins with civilian hands, while B1 survivors wear hazmat suits. | `src/opening-hands.js` defaults to civilian clothing; gameplay/ending use the existing hazmat cast. A brief wake-up/suit detail could explain the change. The new return-through-wall scene already uses the correct hazmat gloves. |

Verified historical recordings: `public/audio/monster.mp3` and `public/audio/jumpscare.mp3` exactly match baseline c47865d by SHA-256. Neural B2 v3 speech ships as four small local MP3s; no online speech service, model weights or inference dependency is required in players' browsers.
